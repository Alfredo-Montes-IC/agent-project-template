# Project customization

Follow [the project customization workflow](../../../docs/workflows/project-customization.md). Inspect existing files, user requirements and code first; preserve existing instructions and decisions. Adapt the canonical `docs/standards/GUIDELINES.md` and other relevant documents instead of copying project-specific reference templates indiscriminately. Mark unverified choices pending, update context routing and client adapters without overwriting user settings, and verify discovery in the clients actually used. Report changes, evidence and unknowns.
