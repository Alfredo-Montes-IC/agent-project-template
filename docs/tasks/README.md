# Task records

Create `<task-id>-<topic>.md` from the [task template](../templates/task.template.md) when durable repository-local context helps. If a GitHub issue is the authoritative task, link it instead of duplicating its status.

Use planned, active, blocked, review, or done status. Identify file ownership and dependencies before parallel work. Attach a [handoff](../templates/handoff.template.md) when ownership changes.
