# Supplied source templates

These folders contain selected, adapted examples for reuse: `Agents`, `Architecture`, `Github`, and `skills`. They are reference material, not project-wide instructions. The current root contract and project requirements take precedence. Adapt names, stack-specific examples, links, policy, legal and compliance claims to the project before use.

The portable [security skill](../../../.agents/skills/security-review/SKILL.md) is the shared starting point. The source material is retained here so an agent without native skill support can still read it by path. Avoid copying example commands or claiming audit certification without verifying applicability and evidence.
